# Data products

Put downloadable data files and their documentation here, using short names with no spaces, such as `county-network-data.zip`.

Link to one from `data/index.html` with `../files/data/county-network-data.zip`.

This folder is public once uploaded, so add only data you are allowed to share.
GitHub's website takes files up to 25 MB, and GitHub rejects anything over 100 MB. Host larger datasets on a data repository, then link to them.
